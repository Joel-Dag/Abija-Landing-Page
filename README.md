# 🏙️ Abija Lab — Architecture & Spatial Research Portfolio

Check it out:https://abija-architectural-firm.vercel.app/

A premium, hyper-minimalist single-page architectural portfolio engineered using Next.js 15, Tailwind CSS, and Framer Motion. This production-grade codebase is meticulously designed for high-end architecture firms, spatial research collectives, and luxury design studios looking for a stark, brutalist aesthetic.

---

## ⚡ Key Engineering Features

*   **Cinematic Typography Reveals:** High-impact hero section leveraging hardware-accelerated splitting layouts that slice text elements across opposing axes upon load.
*   **Sticky Deconstructing Narrative:** A fully customized `useScroll` and `useTransform` layout sequence. As users traverse the timeline, the browser window locks into position to fluidly scale and rotate a geometric matrix layout while structural narrative cards fade into view.
*   **Kinetic Inertial Hover Grids:** An asymmetric project showcase featuring isolated cursor-boundary tracking. Image frames utilize a physics-based spring handler (`useSpring`) that pulls the internal textures toward the pointer with clean, reactive inertia.
*   **Unified Smooth Scrolling:** Seamless integration of the **Lenis** scroll engine, intercepting native hash-routing anchors (`#process`, `#work`, `#studio`, `#contact`) to provide smooth, high-end momentum gliding down the layout canvas.

---

## 🛠️ Tech Stack

*   **Framework:** Next.js 15 (React 19 App Router)
*   **Styling:** Tailwind CSS (featuring custom utility-layer Webkit text-stroke properties)
*   **Motion Architecture:** Motion / Framer Motion (`motion/react`)
*   **Scroll Mechanics:** Lenis Smooth Scroll
